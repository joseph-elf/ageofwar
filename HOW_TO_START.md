# Quick start

## Launch
```bash
cd /Users/josephel-forzli/Desktop/Projects/AgeOfWarII
npm install      # first time only
npm run dev      # open http://localhost:5173
```

## First match (single player)
1. **Single Player** → pick **Easy**.
2. Press `1` to train a unit (costs gold). Queue a few more with `1`, `2`, `3`.
3. Press `Q` to build a turret on your base.
4. Kills give gold + XP. When the XP bar fills, press `V` to **Evolve**.
5. Press `S` to fire your special when enemies are bunched up.
6. Destroy the enemy base (right side) before yours (left) falls.

## Controls
| Key | Action |
|---|---|
| `1`–`4` | Train unit |
| `Q` `W` `E` | Build turret |
| `R` | Buy turret slot |
| `Shift`+`1`–`4` | Sell turret |
| `S` | Special |
| `V` | Evolve |
| `←` `→` / drag / minimap | Scroll |
| `P` / `Esc` | Pause |
| `F3` | Debug overlay |

## Multiplayer (two windows on one machine)
1. Window A: **Multiplayer → Create game** (a 6-character code appears).
2. Window B: **Multiplayer → Join game** → enter the code → **Connect**.
